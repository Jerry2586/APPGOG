# APPGOG 需求基线与验收矩阵

版本：1.0  
状态：已冻结并确认（第 1 阶段完成）  
基线日期：2026-08-29

## 1. 文档目的

本文是 APPGOG 后续设计、开发和验收的唯一需求基线。每项功能必须按本矩阵实现和验收；已有代码、演示数据、线框图或开发便利均不能替代验收结果。

需求来源按以下优先级解释：

1. 产品负责人在当前对话中的最新明确决定。
2. `聊天.txt` 中较晚出现且未被撤销的决定。
3. `项目要求{产品经理}/` 中的三份正式文档。
4. 较早的讨论稿和视觉示例仅作参考，不自动成为真实业务事实。

## 2. 已冻结的核心决定

| 编号 | 决定 | 验收结论 |
|---|---|---|
| DEC-001 | 项目统一名称为 APPGOG。 | 页面标题、配置、文档、包名和部署说明不得出现其他产品名。 |
| DEC-002 | APPGOG 与 Xboard 完全隔离。 | APPGOG 不调用 Xboard API，不连接、不读取、不写入 Xboard 数据库。 |
| DEC-003 | 不实施 SSO 或身份同步。 | APPGOG 不保存 Xboard 用户映射，不识别当前 Xboard 用户。 |
| DEC-004 | Xboard 是黑盒核心系统。 | 登录、注册、套餐、订单、支付、订阅、节点、邀请、工单和流量全部由 Xboard 处理。 |
| DEC-005 | 进入 Xboard 核心业务只能使用普通 URL 跳转。 | 使用 `<a href>` 或浏览器跳转；不得夹带登录令牌、业务参数或调用业务接口。 |
| DEC-006 | APPGOG 前台只调用 APPGOG 主题后台。 | 浏览器网络请求中不得出现 Xboard API 地址。 |
| DEC-007 | APPGOG 主题后台独立运行在 3000 端口并使用独立数据库。 | 部署检查、环境配置和数据库连接检查全部通过。 |
| DEC-008 | 万物皆组件。 | 首页、帮助中心、独立商城和自定义页面均由数据库中的 JSON 组件树生成，不存在写死业务页面。 |
| DEC-009 | 登录后的 Xboard 界面如需换肤，作为独立 Xboard 主题交付。 | Xboard 主题不通过 APPGOG 后端复制或接管 Xboard 业务。 |
| DEC-010 | 删除活动中心。 | 不实现签到、盲盒、抽奖和活动奖励系统，除非未来重新书面加入需求。 |

## 3. 系统归属红线

### 3.1 Xboard 独占功能

以下功能禁止在 APPGOG 数据库中重新实现：

- 用户登录、注册、退出和密码管理
- 用户身份、余额和个人资料
- 流量套餐及流量加油包交易
- 订单、支付和发票业务
- 节点、订阅地址和客户端导入凭证
- 邀请、佣金和返利
- 工单数据和处理流程
- 流量使用记录与明细

### 3.2 APPGOG 独占功能

- 页面、路由、SEO 和 JSON 组件树
- CMS 文章、FAQ、无限分类和视频教程
- m3u8 视频内容
- AI 知识库、RAG 和前台 AI 交互
- 非流量独立增值商品
- 主题皮肤、CSS 变量和调度
- 营销弹窗与倒计时
- 第三方客服、统计和自定义代码注入
- APPGOG 管理后台和审计数据

### 3.3 边界验收

| ID | 验收项 | 通过标准 |
|---|---|---|
| BND-001 | 数据库隔离 | APPGOG 配置、代码和网络记录中不存在 Xboard 数据库连接。 |
| BND-002 | API 隔离 | APPGOG 前台源代码和运行时请求中不存在 Xboard API 调用。 |
| BND-003 | 身份隔离 | 无 SSO、OAuth、共享 Cookie、用户映射或签名登录实现。 |
| BND-004 | 交易隔离 | Xboard 套餐和支付按钮全部为纯 URL 跳转。 |
| BND-005 | 数据不复制 | APPGOG 表结构中不存在 Xboard 订单、余额、订阅、流量或工单镜像表。 |
| BND-006 | AI 不越界 | AI 工具只能读取 APPGOG CMS；不能查询 Xboard 用户或业务数据。 |

## 11. Xboard 纯跳转配置

主题后台只能保存普通 URL：

- Xboard 登录页
- Xboard 注册页
- Xboard 套餐/购买页
- Xboard 用户面板
- Xboard 工单页
- Xboard 联盟营销页（如存在）

验收标准：

- URL 只能是 HTTP/HTTPS。
- 前台使用普通链接跳转。
- 不添加 token、用户 ID 或其他身份参数。
- 不向 Xboard 发送 APPGOG Cookie。
- Xboard 不向 APPGOG 回传业务数据。

## 12. 独立 Xboard 主题交付范围

该交付物与 APPGOG 主题后台分开：

- 菜单保留易懂原名：仪表盘、使用文档、流量商店、我的套餐、我的订单、我的邀请、个人中心、我的工单、流量明细。
- 不擅自把业务名称改成许可证、战术事件、财务审计等术语。
- 登录后不使用官网大型 Footer，只保留简洁版权和安全状态。
- 视觉方向为高级、科技、简洁、易懂，避免传统廉价机场模板。
- 数据来源只能使用 Xboard 主题机制中原本可用的数据。
- APPGOG 后端不为该主题提供 Xboard 业务数据。

是否开发此独立 Xboard 主题，需要在第 13 阶段根据目标 Xboard 版本和官方主题扩展机制单独确认。

## 14. 明确排除项

- APPGOG 与 Xboard SSO
- Xboard 数据库连接

## 16. 阶段一完成条件

阶段一仅在以下条件全部满足后完成：

- 产品负责人确认本文准确表达需求。

- 产品负责人明确下达进入第 2 阶段的指令。

在此之前，不进入架构设计、数据库修改或功能编码。
