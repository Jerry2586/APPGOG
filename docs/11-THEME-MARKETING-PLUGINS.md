## 2. 实施边界与规则

- 页面依然是JSON树。sale/popup/countdown新增可选 campaignId 绑定字段；活动ID可从后台记录卡片取得。类型不匹配、记录不存在或未生效都不渲染，不另建写死商城/活动页面。独立营销时间窗优先，绑定倒计时结束后统一隐藏；本地倒计时的结束提示不继续使用促销标题。
- CSS只接受已声明颜色键和安全值。无脚本、url()、任意CSS注入。新主题需点击“一键设为默认”；当前调度不会被手动切换强制取消。删除默认主题或被任意计划引用的主题会被拒绝。
- API时间必须带Z或偏移；管理表单允许本地墙钟时间并按指定IANA时区换算。夏令时不存在/重复的本地时间拒绝，重复时刻需要显式偏移。时间窗 `[start,end)`，不是含结束点的闭区间。
- 公开配置按当前时间计算，即使后台调度进程暂时失败也不会把过期主题继续作为权威值。后台active标记每15秒追赶，仅真实切换时写系统审计；并发冲突交给下次重试。
- 公开主题/活动/插件覆盖装修页与内容详情，不进入管理页。进入/离开管理入口为整页导航，避免公开插件随SPA上下文进入管理页面。
- 同一插件每个文档只执行一次。修改/停用已执行代码后，配置轮询触发整页重载；后台失败/离线时不能保证即时撤销，恢复网络后才重读。后台停用不等于撤回第三方已接收的数据。
- 自定义HTML/JS是受信任超级管理员扩展，不是安全沙箱。任何可执行代码具有同源权限；同源部署时尤其不能把“仅在公开页插入”当作防恶意管理员或供应链攻击的隔离。必须审核供应商代码、配合CSP与来源策略，严禁身份信息、密钥与Xboard业务调用。实际第三方账号/隐私授权由部署方确认。
- 最多1000条/类；列表有分页。插件最多100000字符/条，同时启用最多16条、UTF-8代码总量512KiB。不得无限堆积脚本损害首屏。非async外部脚本等待load后才执行后续初始化，最长15秒；不会阻塞主要页面渲染。显式async遵循异步语义。
- 弹窗持久频率使用活动ID或既有组件ID，不因修改修订号重新打扰访客。禁用存储时使用同文档内存降级，不能保证跨浏览器会话持久性；浏览器后台定时器节流、多标签同时初次打开的竞争不等于服务器全局频次锁。

## 5. 浏览器证据与技能影响

按浏览器技能使用本机隔离服务，真实运营后台/公开宿主配合内存数据库；代码探针不请求外部客服/统计服务。验证了：

- 上海时区 `2030-01-01 00:00` 至次日调度保存显示正确；新增重叠启用时间窗返回冲突提示。
- 插件HEAD/BODY_END均实测在文档启动约3.1–3.6秒后执行，DOM父节点分别为HEAD/BODY；SPA公开切换保留同一文档和既有脚本，不重复执行。
- 插件历史显示操作者与原因；回退成功创建版本2且保持停用。全程后台探针显示“尚未执行”。
- 已执行公开插件紧急停用后，文档标识由1788190843384变为1788190858474，探针回到“尚未执行”，注入脚本数为0；不是仅删除script标签的假停用。
- 明暗切换后刷新仍保留light偏好，实际body背景为 `rgb(246,247,251)`。
- 最后一轮加载器复核：HEAD本地资源先加载，再在3289ms执行同片段初始化；BODY_END独立在3132ms执行。两个插件之间无依赖，不强制跨插件加载顺序。外部script与后续inline初始化的先后关系实测正确，未请求真实第三方。
- 360px视口弹窗遮罩宽约345px（浏览器滚动条），未越界；Escape关闭后dialog计数为0，刷新仍为0；绑定倒计时结束后timer计数为0，同时普通横幅继续存在。
- VIEWER仅见原有只读内容菜单，不出现主题/营销/插件管理入口，后台HEAD/BODY_END/本地资源探针均未执行；后台通过SPA路由发起公开页导航时触发新文档，不沿用管理上下文。

浏览器验证促使落实实际全局宿主、样式范围和文档生命周期检查。开发时热更新会重载fixture并重置临时页面状态，验证使用新状态重新定位，没有把失效定位器当成功。前端加载器的脚本创建/加载顺序依据 [MDN HTMLScriptElement](https://developer.mozilla.org/en-US/docs/Web/API/HTMLScriptElement) 校核；频率持久性与存储异常依据 [MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) 校核。
