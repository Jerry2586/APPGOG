## 3. 关键行为

- CMS/分类从通用 CRUD 白名单移出，使用独立 DTO、角色校验和事务服务。PATCH 是完整草稿快照；发布和状态操作必须提供 baseRevision。
- 修改已发布内容只改变草稿。发布才替换 publishedSnapshot/publishedSlug/publishedSearchText/publishedHash；搜索、详情与索引都只读公开快照。
- 每个资源修订号递增，陈旧修改返回 409；所有内容/分类变更与审计同一事务。归档/恢复最低 ADMIN，EDITOR 不能用状态接口绕过。
- 关闭投喂立即清理分块并排除检索；更新的草稿不会被重新索引成公开知识。关闭、下线或重新发布期间的旧索引结果会丢弃。
- 索引失败不伪装成发布失败；后台显示真实任务状态。无向量服务时成功的是本地文本分块，明确显示“向量服务未配置”。第十阶段持久工作队列、重排、完整模型运维不在本阶段偷做。
- 富文本与 Markdown 在开始录入前选择；已有非空正文不静默转换格式，避免格式丢失。发布前可预览；切换菜单/离开路由/刷新有未保存保护。
- HLS 不经后端代理；正式视频源需允许 Web 域跨域访问，HTTPS 页面须使用 HTTPS 媒体。签名 URL 过期应更新后发布。
- 前台和后台路由拆分，Quill 不进入前台同步模块，Hls.js 在需要播放时加载。
